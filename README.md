# 🔐 ThreatLens - Cybersecurity Threat Monitoring System

## 📌 Project Overview
ThreatLens is a full-stack cybersecurity threat monitoring system designed to detect, analyze, and visualize security events in real time. It provides a centralized dashboard for monitoring system activities and identifying suspicious behavior efficiently.

---

## 🚀 Features
- Secure user authentication using JWT
- Real-time cybersecurity threat monitoring
- Centralized dashboard for security insights
- User activity tracking and management
- Responsive and modern UI design

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Redux
- React Router DOM
- Ant Design

### Backend
- Node.js
- Express.js

### Database
- MongoDB

User → Login → Authentication (JWT) → Backend API (Node.js + Express) → Database (MongoDB) → Dashboard → Real-time Threat Monitoring

🎯 Objective

To build a centralized system for monitoring cybersecurity threats and providing real-time visualization of suspicious activities.
